# Picante System

Internal business management system for Picante Premium Food Brand.

## Current Architecture

- Retool (Staff Interface)
- Supabase (Backend)
- PostgreSQL (Database)

## Planned Features

- Role-based access control
- Row Level Security (RLS)
- Audit logging
- Inventory management
- Order management

## Project Goals

- Build a production-style internal business system
- Apply cybersecurity principles
- Develop a portfolio-quality case study
